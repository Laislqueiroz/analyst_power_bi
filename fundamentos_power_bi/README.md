# 📊 Desafio Power BI - Análise de Vendas e Lucro (DIO)

Este repositório contém a resolução do desafio prático do bootcamp de Power BI da DIO. O objetivo principal do projeto é aplicar conceitos de criação de visuais, formatação, dicas de ferramentas (*tooltips*) e publicação de relatórios a partir da base de dados *Financial Sample*.

---

## 📌 Estrutura do Relatório

O relatório foi dividido em 3 páginas principais:

* **Página 1 e Página 2:** Réplicas dos painéis desenvolvidos ao longo das aulas práticas do módulo.
* **Página 3 (Desafio Individual):** Página desenvolvida para praticar a criação e alinhamento de visuais:
  * **Mapa 1:** Soma de Vendas (*Sales*) e Unidades Vendidas (*Units Sold*) por País (com Dica de Ferramenta configurada).
  * **Mapa 2:** Soma de Lucro (*Profit*) por País.
  * **Gráfico de Pizza:** Distribuição de Lucro (*Profit*) por Segmento.

---

## 🛠️ Boas Práticas Aplicadas

* **Nomenclatura Limpa:** Personalização dos títulos dos visuais para termos claros e diretos em português.
* **Dicas de Ferramenta (Tooltips):** Formatação adequada dos campos numéricos exibidos ao passar o mouse sobre os mapas.
* **Disposição Visual:** Alinhamento e distribuição simétrica dos elementos na tela.
* **Publicação e Integração:** Relatório publicado no Power BI Service e preparado para apresentação no Microsoft PowerPoint.
